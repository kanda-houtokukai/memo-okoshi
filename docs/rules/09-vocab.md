> 2026-10-14 台帳の「いま守る制約（主題別）」から分けた（P24）。

- ⚠️ **端末内（localStorage `memo-okoshi:vocab`）にだけ保存**し、変換リクエストに同送してプロンプトへ差し込む。
  サーバーは `sanitizeForPrompt` で絞って使うだけで**保存しない**。
- **分類なしの単純リスト**（語＋任意の意味）。上限 200語・語40字・意味60字。
- **初期セットは入れない**。空のときはプロンプトに節を出さない。
- ⚠️ **人名を入れさせない配慮**: ①敬称で終わる語は登録拒否 ②黄からの学習導線は赤には出さない
  ③プロンプトで明示 ④**「辞書に追加」では、その記録で赤になった語（姓・名だけの形も）を弾く**（P15。`tests/vocab.test.mts`・`tests/red.test.mts`）。**敬称なしの姓名は機械では見分けられない**
  → AI委員会の申し合わせ（運用）で補う前提。
- プロンプトの指示は「該当しそうなら優先採用。**ただし書かれていない語を辞書から補わない**」。
- **説明文を足さずに「例」で伝える**: プレースホルダーを具体例に／**空のときだけ**淡い例示3件。
  例示は**表示専用**（`VOCAB_EXAMPLES`）で保存もプロンプト送信もしない。特定の法人・事業所が分かる語は使わない。
- 学習導線は**黄ポップオーバーの「辞書に追加」チェック**（既定オフ）。見出しは**「事業所の言葉」**。
  ※**プロンプト内の節名「組織の語彙」はAI向けなので据え置き**。入力欄は **16px**。
- 書き出し／読み込みは JSON 1ファイルに辞書＋**面談と会議の設定**（項目の選択・並び・自由形式。会議は `meeting` の中）を同梱
  （辞書＝追記・人名ガード、設定＝置換。**設定したことがないものは入れない・会議の設定が無い古いファイルも読める**。`tests/meeting.test.mts`）。
