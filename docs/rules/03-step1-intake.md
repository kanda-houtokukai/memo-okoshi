- 画面は「机の上に紙を並べる」。**固定ビューポート**（`.ik-root` ＋ `html.lock`。机だけが内側でスクロールする）。
- **経路の出し分け**: iOS/Android＝3経路（カメラ／写真ライブラリ／ファイル）、PC＝ファイル1経路＋D&D。
  **PCにカメラ経路を出さない。** 判定が外れてもファイル経路は常に使える。
- **1回の変換＝複数画像＝1件の記録。**
- **PDFは端末内でページ画像化**してから伏せる工程へ。**入力形式によらず全ページが伏せる工程を通る。**
- **並べ替えは ←→ ＋ ドラッグ**（タッチはつまみ ⠿ からのみ・マウスは紙の本体からも掴める）。
  **ドラッグと←→が同じ結果になること**（`tests/reorder.test.mts`）。
- 空きスロットは**机の左上**・紙と同じ **228×314**。後ろに**薄い枠2つ**（≤720px では1つ）を控えさせる。
  薄い枠も**押すと取り込みメニューが開く**が、**読み上げには出さない**。
- **紙が1枚以上のときだけ**画面下に操作の帯（左＝枚数・右＝「次へ」）。**0枚なら帯を出さない**（勝手に進ませない）。
  ヘッダーに同じボタンを重ねて置かない。文言は行き先ではなく「次へ」。
- **読み込めないファイルは名前を出してトースト**（黙って捨てない・原則2）。
- 送信画像は **JPEG 品質0.92・最長辺2200px**。
