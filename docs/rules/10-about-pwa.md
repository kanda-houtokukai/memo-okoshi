# 使い方ページ・アイコン・PWA

> 生きた決まり（主題ファイル）。索引は台帳 `memo-okoshi-handoff.md` の「主題の索引」。書き足し方は CLAUDE.md「台帳の維持」。
> なぜそうしたか（経緯・実測）は `memo-okoshi-archive-2026-09.md`。ここには置かない。
> 2026-10-14 台帳の「いま守る制約（主題別）」から分けた（P24）。

- `/about` は**作業画面の外の独立ページ**（作業の流れに説明を差し込まない）。入口は全工程のヘッダー・辞書の左で、
  **冊子アイコン＋「使い方」**。**別タブで開く**。
- ⚠️ **`/about` は合言葉ゲートの外側**。載るのは仕様と運用ルールだけで、**法人名・施設名・個人情報・合言葉を書かない**。noindex は維持。
  ⚠️ **ゲートを開けるのは `middleware.ts` の `PUBLIC`（完全一致の Set）に並べた道だけ。前方一致にしない。**
- ⚠️ **会議の章は足さない。違うところは該当する章に一文ずつ**（冒頭で面談を例と断る。`tests/about.test.mts`）。
- **文面の正本は `lib/about-copy.ts`。** `app/about/page.tsx` は器だけで文字を持たない。
  **文の作法**（一文を短く・すべての文を述語で終える・見出しは文にしない。`tests/about.test.mts`）。
  ⚠️ **文面・章の順・公開する道を変えるときは、設計側の承認を取ってからテストも一緒に直すこと**
  （控えは `tests/about.test.mts`。1文字でも変わると落ちる）。
- ⚠️ **画面写真の原本は `docs/assets/help/`、配信は `public/help/`**（同じ中身を無加工で置く）。
  写っているのは**生成したダミーのメモ**。**差し替えるときも同じ確認をしてから。**
  冒頭に「画面の例はすべて架空のものです。」を必ず置く。写真は `loading="lazy"` ＋実寸指定、押すと原寸が別タブで開く。
  ⚠️ ゲートを通すのは **1枚ずつ完全一致**（`HELP_SHOTS`）。**`/help/` の前方一致にしない**。
  撮り直すときは **`docs/assets/help/shoot.mjs`**（**撮影用のビルド `npm run build:shoot` で**・1345×775・倍率1・原本と配信の両方に書く）。**ファイル名を変えない**。
  ⚠️ **開発データ（`?fixture=1`・`lib/dev-fixture.json`）は撮影用のビルドだけ**。public/ に置かない・本番のビルドに入れない（`tests/fixture.test.mts`）。
  確認画面・出力の写真（08・09・11）は**開発データ `?fixture=1` を画面の操作で整えて**撮る。11 だけは出力画面の範囲を切り出す（`{ clip }`・`tests/about.test.mts`）。
- **目次は小口のインデックス（案B・`tsukaikata-index-mock`）。部品は `ChapterIndex` の1つで読みものと共有**。880px以上は紙の右端の縦のインデックス、
  未満は上に貼り付く帯（一覧は外側・Esc・選ぶで閉じる）。⚠️ **縦の文字は writing-mode でなく1字ずつ改行**。移る間は表示を揺らさない・
  視差効果を減らす設定では動かさない（`tests/yomimono.test.mts`）。
  ⚠️ **「最下端なら最後の章」の規則は使わない**（上がりきらない章は最下端の手前に 80px ずつ割り当て、どの章も一度はいまの章になる）。⚠️ **章は目次の id で読む**（位置の番号で読まない。`tests/about.test.mts`）。
- 「メモを書く」は用紙と取り込みの間・番号なし・コツは色の四角・最後に読みものへの入口（差し込みの紙）。
- **読みもの `/yomimono/…` もゲートの外**（`PUBLIC` に1本ずつ完全一致・noindex）。文面の正本は `lib/yomimono-copy.ts`（モックの文面のまま。
  変えるときは設計側の承認とテストを一緒に）。一覧は `READINGS` の1か所（`tests/yomimono.test.mts`）。
- ⚠️ **手書き風の字（Klee One）は読みもの・ホームの棚・開発データの元メモだけが読む**（`lib/hand-font.ts`。共通の layout で読まない）。
- **体裁の設計意図は `tsukaikata-mock-v3`**（凍結・参照のみ。正本は実装）。
  ⚠️ **部品名を作業画面の規則とぶつけない**（手順の入れ物は `.ab-steps`）。
  ⚠️ **横あふれは各幅（375〜PC）で実測して0**にする（`tests/about.test.mts`）。
- **PWA は standalone**。**Service Worker・オフライン対応はやらない**。
- アイコンは**設計側が生成した原本を縮めるだけ**（sips）。**原本は加工しない。** maskable は宣言しない。
  **大小で別デザイン**（16/32px と 48px以上で原本が違う。`tests/icon.test.mts` が原本2枚の md5 を控えている）。
