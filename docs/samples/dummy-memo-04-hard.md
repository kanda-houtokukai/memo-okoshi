# dummy-memo-04-hard の原本（ground truth）

架空の相談支援モニタリング面談。実在の人物・事業所とは関係がない。
既存のダミー3枚がいずれも**児童面談**で字も整っていたため、**成人（就労・金銭管理）**の題材で、
**判読しにくい**素材として 2026-09-10 に作った（P7-c のモデル比較用）。

## 書いてある内容（正解）

```
モニタリング 9/12(木) 14:00〜 自宅訪問
本人 ＋ 姉 同席
【生活】
・起床 7:00 頃、朝食は 食べたり 食べなかったり
・週3 で B型作業所（送迎あり）
・部屋の 片づけが 苦手 → ヘルパーと 一緒に 月2回
【服薬】
・眠剤 は 自己管理、飲み忘れ 週1〜2
・訪看 から 声かけ もらっている
【就労】
・工賃 は 月 12,000円 くらい
・「もう少し 増やしたい」との 発言
・サビ管 と 個支計 の 見直しを 10月に 予定
【困りごと】
・金銭管理、月末に 苦しくなる
・姉「本人に 任せると 使いすぎる」
【次回】
・ケース会 10/3 、モニタ は 11月
```

## わざと読めなくした5か所（**ここを黄で申告できるか**が最重要の観点）

| 箇所 | 正解 | 潰し方 |
|---|---|---|
| 服薬1行目の先頭 | 眠剤 | 強いにじみ |
| 服薬1行目の末尾 | 週1〜2 | にじみ |
| 服薬2行目の先頭 | 訪看 | 最も強いにじみ |
| 就労1行目 | 月 12,000円 | にじみ（桁が読めない） |
| 次回 | 10/3 | にじみ |

**人が見ても読めない**ように潰してある。ここを埋めてくる回答は「自信ありげな誤読」であり、
黄（読み取りに自信なし）で申告するのが正しいふるまい。

## 文脈が要る略語（潰していないが、福祉の文脈を知らないと読み違える）

サビ管（サービス管理責任者）／個支計（個別支援計画）／訪看（訪問看護）／モニタ（モニタリング）／B型（就労継続支援B型）

## 作り方

`docs/samples/make-dummy-04-hard.py`（PIL＋macOS の Klee フォント。1文字ごとに回転・大きさ・濃さ・
詰まりを散らし、5か所をにじませる。乱数の種を固定してあるので同じ画像が再現できる）。
