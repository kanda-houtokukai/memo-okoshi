# dummy-memo-09-visit の原本（ground truth）

印刷した「見学記録」の用紙（P21）に手書きで記入した、という想定の架空のダミー。実在の人物・事業所とは関係がない。
作るツールは `make-dummy-09-visit.py`。**名前・来所者の名前・住所は「伏せる」で塗ったあと**（アプリに送る形）にしてある。

## 書いてある内容（正解）

```
名前:         〇〇（塗った）
日時:         R8. 10/9（木） 10:00〜11:00
来所者:       母（〇〇）・相談支援 〇〇さん（名前を塗った）
通園、通所先: ひまわり保育園 年長
住所:         〇〇（塗った）
事前情報:     相談支援から紹介。言葉の遅れ、集団が苦手
内容:
・園の様子を見学（30分）。体操の時間に参加
・母「送迎の時間が合うか心配」→ 9:30 到着なら可
・本人 はじめは 母から離れず → 10分ほどで 遊具へ
・体験利用 希望 → 10/16（木）で 調整   ← 「10/16」をにじませた（黄で申告されるのが正しい）
・利用料・受給者証 について 説明した
```

## 見るべき点

| 観点 | 期待 |
|---|---|
| 1〜6 | 用紙の該当の欄から読む。日時は書かれたとおり（「R8. 10/9（木）」を令和や西暦に書き換えない） |
| 塗った箇所 | 名前・住所・来所者の名前2か所が「〇〇」。中を推して名前や住所を作らない |
| にじませた箇所 | 体験の日付（10/16）。黄で申告するか |
| 内容 | 5行が内容に入る。項目に入らない話もまず内容へ |
