# dummy-memo-06-meeting-sheet の原本（ground truth）

印刷した「会議記録メモ」（P9-c の会議の用紙。2026-09-17 P9-d で「今後の対応」・内容23本/決定事項と今後の対応6本に作り直した）に手書きで記入した、という想定の架空のダミー。
実在の人物・事業所とは関係がない（「山本」「ひだまり」も架空）。作るツールは `make-dummy-06-meeting-sheet.py`。

**会議名は頭の「会議名」欄にだけ書いてある**（本文の枠には出てこない）。AIが頭の記入欄から会議概要を組み立てられるかを見る素材。

## 書いてある内容（正解）

```
【頭】
会議名: 第2回 送迎検討会
日時:   R8 年 9 月 24 日 15 時 00 分 〜 16 時 10 分
場所:   ひだまり 2階 相談室
出席者: 管理者・サビ管 山本・支援員2名・運転手
押印欄（作成者／署名）: 空欄

【内容】
【送迎ルート】
・朝便 A ルート 9:20 着 が 多い（15分 遅れ）
・保護者から 事前連絡 が ほしい との声
・B ルートと 入れ替える 案 → 運転手さん 了承
【車いす 対応】
・リフト車 1台 のみ、雨の日 乗降 に 時間
・スロープ の 位置 を 変える 案、要見積

【決定事項】
・10/1 から A・B の 順番を 入れ替える
・遅れる時は 8:50 までに 電話 連絡 する

【今後の対応】
・新時刻表 作成 → 山本 9/30 まで
・スロープ 見積 依頼 （担当？）

【その他】
・次回 10/22(水) 15:00
```

## 見るべき点

| 観点 | 期待 |
|---|---|
| 会議名 | **会議概要に「会議名：第2回 送迎検討会」**が入る（頭の欄から読む） |
| 日時・場所・出席者 | 会議概要に行を分けて入る。空欄の行は書かない |
| 人名（山本） | 赤にならず本文に残る |
| 今後の対応 | スロープ見積は担当を補わない（担当未定） |
| その他 | どの項目にも当たらなければこぼれ枠へ（黙って捨てない） |
